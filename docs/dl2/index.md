# 💻 Wie funktioniert ein Computerprogramm?

## 1. Grundidee
- Ein Programm ist eine **Anleitung für den Computer**
- Prinzip: **Eingabe → Verarbeitung → Ausgabe**
- Beispiel: Ein Taschenrechner nimmt Zahlen, rechnet, zeigt Ergebnis

---

## 2. Sprachebene
- Programme werden in **Programmiersprachen** geschrieben
  - **Hochsprachen**: Python, Java, C++
  - **Maschinensprache**: 0 und 1
- Damit der Computer versteht:
  - **Compiler** (übersetzt alles auf einmal)
  - **Interpreter** (übersetzt beim Ausführen)

---

## 3. Ablauf im Computer
1. **Laden**: Programm in den Arbeitsspeicher
2. **Ausführen**: CPU arbeitet Befehl für Befehl ab
   - z. B. „Addiere“, „Springe zu ...“
3. **Steuerung** durch Kontrollstrukturen
   - *Wenn–dann*, *Wiederhole bis*

---

## 4. Daten und Variablen
- Programme arbeiten mit **Daten** (Zahlen, Text, Bilder …)
- Daten liegen in **Variablen** (wie kleine Schubladen im RAM)
- Befehle ändern oder kombinieren diese Daten

---

## 5. Logik und Algorithmen
- Jedes Programm basiert auf einem **Algorithmus**
- = genaue Abfolge von Schritten, um ein Problem zu lösen
- Beispiel: Sortieren von Zahlen

---

## 6. Interaktion
Programme können:
- Eingaben vom Benutzer oder Sensoren erhalten
- Entscheidungen treffen (Logik)
- Ergebnisse anzeigen oder speichern

---

## 📝 Zusammenfassung
- Ein Computerprogramm = **Folge präziser Anweisungen**
- Wird in Maschinencode übersetzt und von der CPU Schritt für Schritt ausgeführt
- Arbeitet nach dem Muster:
  **Eingabe → Verarbeitung → Ausgabe**
