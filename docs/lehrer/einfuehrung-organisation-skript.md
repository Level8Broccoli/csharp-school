# Einführung & Organisation

*Kontext: Berufsschule (Informatik-Grundkurs) · Dauer: 90 Min · Zielgruppe: Lernanfänger ca. 16 Jahre, kein Vorwissen*

**Lernziel:** Die Lernenden kennen den Kursablauf, haben eine funktionierende Entwicklungsumgebung (VS Code + C#) sowie einen GitHub-Account eingerichtet und haben ihr erstes C#-Programm ausgeführt.

## 1. Einstieg

- Als Einstieg das eigene **Smartphone hochhalten** und fragen, wo den Lernenden im Alltag überall Software begegnet, die einmal von jemandem programmiert wurde – Apps, Games, Kassensysteme im Laden.
- Kurz in die Runde fragen, **wer schon einmal etwas programmiert hat und was** das war, um ein Gefühl für das Vorwissen der Klasse zu bekommen.
- Die **Diskussionsfrage** stellen: "KI kann doch schon programmieren – wieso lernen wir das dann noch?" Zuerst drei Minuten in Kleingruppen murmeln lassen, danach die Argumente gemeinsam an der Tafel als Pro/Contra sammeln.
- Falls in der Diskussion nicht von selbst genannt, folgende **Kernargumente** ergänzen:
    - KI-generierter Code muss verstanden, geprüft und bei Fehlern korrigiert werden können – das setzt eigenes Grundwissen voraus. Wer die Grundlagen nicht kennt, kann weder gute Prompts formulieren noch beurteilen, ob ein KI-Vorschlag überhaupt stimmt.
    - Die Lehrabschlussprüfung verlangt zudem Code-Verständnis ohne KI-Hilfe. Das Berufsbild verändert sich, aber das Verständnis für Logik und Code bleibt die Grundlage, um KI als Werkzeug sinnvoll einzusetzen statt ihr blind zu vertrauen.
- Einen kleinen **Ausblick** geben: Am Ende des Semesters sollen alle in der Lage sein, ein eigenes kleines Programm mit eigener Logik zu schreiben – und damit auch KI-generierten Code kompetent zu beurteilen.

## 2. Grundlagen

- Den **Modulüberblick** zeigen und erklären, aus welchen Bausteinen das Semester besteht: theoretische Grundlagen, praktisches Programmieren, Arbeiten mit Git und GitHub sowie drei Prüfungen. Kurz erwähnen, dass die Inhalte eng an der Lehrabschlussprüfung orientiert sind.
- Anhand eines Alltagsbeispiels erklären, was ein **Code-Editor** wie VS Code ist und wozu die Programmiersprache C# dient: Ein **Programm ist wie ein Rezept** – eine Anleitung, die der Computer Schritt für Schritt abarbeitet.
- **GitHub** als Plattform vorstellen und begründen, wozu sie im Kurs gebraucht wird: um eigenen Code zu sichern, später mit anderen zusammenzuarbeiten und sich langfristig ein kleines Portfolio aufzubauen.
- Den Ablauf der heutigen Doppellektion transparent machen: Zuerst wird die Entwicklungsumgebung gemeinsam eingerichtet, danach arbeiten die Lernenden die ersten Schritte selbständig durch.

## 3. Anwendung

- **Entwicklungsumgebung einrichten:** Die Lernenden installieren die .NET SDK und Visual Studio Code und richten die C# Dev Kit-Erweiterung ein.
- **GitHub-Account und erstes Repository:** Die Lernenden erstellen einen GitHub-Account (sofern noch nicht vorhanden) und legen ein erstes Repository für den Kurs an ("csharp-kurs-[Nachname]") an. Wer will, ergänzt zusätzlich ein Profilbild und eine kurze Profilbeschreibung. Erwartetes Ergebnis: Ein sichtbares, korrekt benanntes Repository im eigenen GitHub-Profil.

## 4. Transfer

- Zum Abschluss kurz in der Runde fragen, wer **"Hello World"** erfolgreich zum Laufen gebracht hat und wo es Stolpersteine gab, um allfällige offene Probleme noch vor Kursende zu lösen.
- Einen **Ausblick auf die nächste Lektion** geben: Wie ein Programm eigentlich "läuft" – Compiler versus Interpreter.
- Darauf hinweisen, dass das heute eingerichtete **Setup und Repository** während des ganzen Semesters weiterverwendet werden.
